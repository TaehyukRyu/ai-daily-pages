자세히 보기

Claude Code v2.1.318이 나왔다. 공식 릴리스 노트에서 눈에 띄는 변화는 mod의 `$.model.fork`에 `effort` 옵션이 생긴 점이다. mod는 Claude Code의 동작에 사용자가 기능을 덧붙이는 확장이고, effort는 모델이 얼마나 공들여 추론할지 정하는 값이다. 이제 세션이 어떤 effort로 돌든 간단한 보조 작업만 `low`로 돌릴 수 있고, 결과에는 실제로 보낸 effort가 함께 나온다.

자동화 환경에서 쓸모 있는 변화도 있다. 저장된 claude.ai 로그인이 끝나는 날짜가 `claude auth status`에는 `loginExpiresAt`으로, `claude -p`의 JSON 결과에는 `credential_expires_at`으로 표시된다. `claude -p` 텍스트 출력에는 로그인이 끝나기 10일 전부터 표준 오류(stderr)로 경고가 한 줄 나온다. 밤새 돌던 작업이 로그인 만료로 멈추는 일을 미리 막을 수 있는 장치다.

이 밖에 세션 중 Claude Code가 직접 쓴 mod를 켤지 물었을 때의 답을 기록으로 남기게 됐다. Claude apps gateway(Claude 앱 요청을 중계하는 관문)의 mantle 업스트림에는 `assume_role`이 추가됐다. 다른 AWS 계정의 역할을 쓰거나 개발자별로 AWS 비용을 나눠 볼 때 쓰는 설정이다.

고친 버그는 훨씬 많다. 2.1.314에서 생긴 문제로 잘못된 도구 호출의 재시도가 끝나면 `--continue`가 이전 대화를 잃는 경우가 있었는데 이를 바로잡았다. Bash 명령을 많이 돌리는 macOS 세션이 메모리가 늘며 멈추던 문제, 메시지를 보낸 직후 친 키가 권한 확인 창의 답으로 처리되던 문제도 고쳤다. 후자는 의도하지 않은 승인으로 이어질 수 있어 눈여겨볼 수정이다.

유휴 상태의 대화 압축이 요약이 아닌 답변으로 대화를 덮어쓰던 문제, 백그라운드 서브에이전트가 도는 동안 'Now using usage credits' 알림이 약 30초마다 다시 뜨던 문제도 고쳤다. `claude mcp add`와 `remove`는 이제 설정 파일 잠금을 기다리거나 코드 1로 끝난다. 다만 릴리스 노트는 다른 작업의 저장이 등록한 서버를 덮어쓸 수 있다고 함께 밝혔다.

여러 터미널과 원격 실행 환경의 문제도 다뤘다. 다른 터미널에서 같은 계정으로 다시 로그인하면 작업이 `Not logged in`으로 끝나던 문제, 업데이트로 실행 중인 프로세스의 바이너리가 지워져 `claude remote-control`과 자체 호스팅 러너가 새 세션을 띄우지 못하던 문제(`spawn ENOENT`)가 해결됐다. 클라우드 세션 재시작 뒤 승인된 셸 명령이 요청한 폴더가 아니라 시작 폴더에서 실행되던 문제도 고쳤다. 이제 그 폴더에 들어갈 수 없으면 명령을 실행하지 않는다.

화면 초안을 순서대로 만들어 주는 오픈소스 스킬이다. 토스풍 여부는 확인되지 않았다
  • PRD를 넣으면 시작·보기·고치기·끝 화면을 만드는 MIT 오픈소스다
  • Claude Code·Codex·Cursor용 플러그인으로 제공된다
  • '토스풍'은 확인되지 않았고, README는 초안용 도구라고 밝힌다
자세히 보기

기획 문서 한 장을 넣으면 한국 앱 스타일의 화면을 순서대로 만들어 준다는 스킬 k-style-ui-ux가 유튜브 채널 바이브마피아의 영상들로 소개됐다. 저장소 README를 확인한 결과 PRD(제품 요구 사항 문서)를 입력받아 시작·보기·고치기·끝 화면을 만드는 구조이고, 라이선스는 MIT다. Claude Code뿐 아니라 Codex, Cursor용 플러그인으로도 제공된다.

영상 제목과 설명은 '토스·당근 같은 디자인'을 내세우지만 이 대목은 그대로 받아들이기 어렵다. README에서 당근은 색 팔레트의 출처로 나오고, 토스는 언급을 찾지 못했다. README는 이 도구를 초안용이라고도 밝힌다. 곧바로 출시할 완성 디자인을 뽑는 도구가 아니라 방향을 빠르게 잡는 출발점으로 보는 편이 맞다.

함께 올라온 짧은 영상 다섯 편은 모두 「K-디자인 하네스를 소개합니다」 라이브에서 발췌했다. 하네스는 AI가 일할 때 지켜야 할 규칙과 도구, 검사 절차를 묶은 틀을 뜻한다. 제목은 'AI 디자인, 왜 티가 날까요?', 'AI로 디자인할 때 피그마 써야 할까?', '하네스에 꼭 넣어야 하는 것', '하네스가 1시간씩 걸린다면', 'UI랑 UX, 하나만 챙긴다면?'이다. 설명란에는 영상별 결론이 적혀 있지 않아, 각 편의 주장은 이번에 확인하지 못했다.

소개 쇼츠 한 편은 영상 속 인물이 얼굴과 목소리 모두 AI로 만든 클론이라고 설명란에 밝혔다. 사용법과 프롬프트 요령을 담은 자료 링크도 안내했다.

AI에게 앱을 시켰다가 웹페이지 같은 결과만 받아 본 사람을 겨냥한 Claude Code 플러그인이 소개됐다. BAMA는 아이디어부터 Dock에 올리는 단계까지 Mac 앱 제작을 돕는 플러그인이다. 스킬 21개를 담았고, Mac 앱을 만드는 언어 Swift와 화면 틀 SwiftUI를 쓴다. 모두 저장소 README로 확인됐다. 저장소는 2026년 10월 24일 공개됐다. 영상은 11월 3일 GitHub API로 확인한 별이 1,459개라고 전했다.

영상 설명에 따르면 작업 방식은 이렇다. 마음에 드는 앱의 화면을 전부 찍어 밑그림으로 삼고, 기능은 체크할 수 있는 목록으로 나눠 단계별로 만든다. 크기와 글꼴, 색을 재서 픽셀 단위로 비교하며 원래 화면에 맞춘다.

처음부터 구상하기 어렵다면 설계도를 쓸 수 있다. 창 정리, 클립보드 기록, 화면 녹화 같은 작은 Mac 앱 설계도 12개가 들어 있어 파일 하나로 시작할 수 있다. 품질 확인 절차도 정해 뒀다. 커밋(변경 내용 저장) 전마다 모든 화면을 밝은 모드와 어두운 모드로 찍어 보고 테스트를 돌린다. 이 내용도 README 문구와 일치한다.

공식 문서로 확인되는 것은 세션 가져오기와 Stop 훅이다. 데스크톱 앱의 설정 > Import에서 최근 30일 대화를 가져올 수 있다. 영상은 대화를 워크트리나 클라우드로 넘기는 핸드오프 메뉴와 구분하라고 당부한다. Stop 훅은 AI가 턴을 끝내려 할 때 끼어드는 장치로, block 결정을 내리면 작업을 계속하게 할 수 있다. 영상은 이를 이용해 테스트가 실패하면 끝내지 못하게 하는 '검증 게이트'를 만들었다. 이 테스트 예제 자체는 공식 문서가 아니라 영상의 내용이며, 훅 승인과 앱 재시작 과정도 함께 확인하라고 안내한다.

확인되지 않은 기능도 있다. `reasoning_effort_override`로 추론 수준을 바꿔도 캐시를 유지한다는 설정은 공식 문서에서 찾지 못했고, 영상도 실험 기능이라고 밝힌다. 영상의 캐시 수치는 그 실행에서 관찰한 결과일 뿐이다. 사이드 채팅과 반복 작업을 녹화해 스킬로 만드는 기능도 공식 문서로 확인하지 못했다. 문서 메뉴에는 Record & Replay만 보인다.

대화 드래그로 참조하는 기능은 코덱스 대화에서 확인했지만, 클로드에서 가져온 대화는 영상의 실행에서 참조 오류가 났다고 한다. 영상에 함께 소개된 ide-mod는 Claude Code 플러그인이다. 핸드오프 화면에서 y는 세션 ID를, c는 핸드오프 글을 복사한다. 가장 분명한 것은 칠레 사례다. 데이터센터가 주민 전체의 1000배에 달하는 물을 쓴다는 수치는 오류다. 저자 캐런 하오의 정정 글에 따르면 구글이 허가받은 최대치인 초당 169리터, 연 약 53억 리터를 주민 사용량 약 51억 리터와 견주면 약 1.045배다. 실제 사용량이 아니라 허가 최대치 기준이라는 점은 짚어 둬야 한다.

그런데 글이 밝힌 오류의 원인은 틀렸다. 글쓴이는 초당 리터와 시간당 세제곱미터를 혼동한 탓이라고 했지만, 정정 글은 정부 문서가 세제곱미터 값을 리터로 표기한 것이 원인이라고 설명한다. 실제 사용량이 도시의 약 0.22배, 지역 상수도의 3% 정도라는 대목은 앤디 매슬리의 원문이나 공식 자료를 찾지 못해 확인되지 않았다.

온도 수치는 절반만 확인된다. 데이터센터 주변 지표 온도가 평균 약 2°C 올랐다는 연구는 arXiv 초록에서 확인됐다. 공기가 아니라 땅 표면 온도를 잰 연구이고, 저널 게재 표시가 없는 동료 심사 전 논문이다. 극단적인 경우 9°C 올랐다는 수치는 포천 보도에만 있고 초록에는 없다. 글이 지적한 '15.5도 상승' 수치의 근거 유무도 이번에 따로 확인하지 못했다.
