앤트로픽이 Claude Code v2.1.312를 내놨다. 전날 나온 v2.1.311이 긴 CLAUDE.md 때문에 생기던 멈춤과 SubagentStop 훅 중복 실행을 고쳤는데, 이번 판은 기업용 로그인 설정 하나를 더하고 메모리 파일, 훅, 스킬 관련 문제를 손봤다.

가장 눈에 띄는 새 기능은 Claude 앱 게이트웨이의 `oidc.user_id_claim` 설정이다. OIDC는 회사 계정 하나로 여러 서비스에 로그인하게 해 주는 표준인데, 로그인하면 사용자 정보를 담은 id_token을 받는다. 지금까지는 이 토큰의 기본 식별값인 `sub`으로 사람을 구분했다. 이제는 Microsoft Entra ID의 `oid`처럼 다른 값을 골라 쓸 수 있다. 회사 디렉터리의 사용자 ID와 Claude 사용 기록을 맞춰 보려는 조직에 쓸모가 있다.

메모리 파일 쪽에서는 사고를 막는 수정이 들어갔다. 하위 폴더에 있는 아주 큰 CLAUDE.md나 규칙 파일, @로 불러온 파일을 Claude가 앞부분만 보고 통째로 덮어쓰는 일이 있었다. 이제는 Write 도구가 파일 전체를 먼저 읽거나 제자리에서 고치라고 Claude에게 요구한다. 오래 쌓아 온 지침 파일을 날릴 위험이 줄었다.

훅 실행 방식도 바뀌었다. 프롬프트 훅과 에이전트 훅은 서브에이전트까지 합쳐 세션당 한 번에 최대 24개까지만 돈다. 이벤트 제한 시간을 넘겨 기다리는 훅은 여기에 더해 최대 12개까지 허용한다. `timeout`을 1초보다 짧게 적으면 1초로 친다. 훅을 많이 걸어 둔 사람은 동시에 몰리는 경우 순서가 밀릴 수 있다.

스킬과 명령 관련 버그도 고쳤다. Bash로 git 저장소 안쪽 폴더에 `cd`하면 폴더별 스킬과 `paths:` 스킬을 찾지 못하던 문제, 이름이 잘못된 명령 하나 때문에 명령 전체가 안 불러와져 `claude -p`가 아무것도 출력하지 않던 문제가 해결됐다. VS Code 확장에서 로그인한 뒤 관리 설정과 조직 정책을 세션 내내 불러오지 못하던 문제도 고쳤다.

서브에이전트의 `autoCompactWindow`는 이제 `CLAUDE_CODE_AUTO_COMPACT_WINDOW`로 정한 창을 실제로 낮출 수 있다. 자동 압축(대화가 길어지면 앞부분을 요약해 줄이는 기능)을 서브에이전트에서 더 일찍 일으키고 싶을 때 쓴다. 높이는 쪽으로는 여전히 쓸 수 없다.

Bedrock·Vertex·Foundry·Mantle에서 Claude Code가 모르는 모델 이름(직접 붙인 배포 이름이나 추론 프로필 ARN)을 쓰면 이제 짧은 시스템 프롬프트를 쓴다. 전체 프롬프트를 유지하려면 `CLAUDE_CODE_SIMPLE_SYSTEM_PROMPT=0`을 설정하면 된다. 사용량 한도 안내에서는 '세션 한도'라는 말 대신 '5시간 한도'라고 부른다. OpenTelemetry의 `claude_code.safety_event` 이벤트는 더 이상 보내지 않는다.

Claude Code가 CLAUDE.md를 언제, 어디까지 읽는지 실제 화면으로 보여 준 영상이 나왔다. CLAUDE.md는 Claude에게 프로젝트 규칙과 맥락을 알려 주는 지침 파일이다. 영상 내용 중 핵심은 공식 메모리 문서와 일치한다.

Claude Code를 켠 폴더와 그 위 폴더들의 CLAUDE.md는 시작할 때 모두 읽는다. 서로 덮어쓰지 않고 위에서부터 이어 붙여서, 켠 폴더에 가까운 파일이 가장 나중에 들어간다. 반면 아래 폴더의 CLAUDE.md는 Claude가 그 폴더의 파일을 열거나 고칠 때 읽는다. 이때 터미널에 'Loaded api/CLAUDE.md' 같은 줄이 뜬다.

읽는 곳은 세 군데다. 홈 폴더의 `~/.claude/CLAUDE.md`는 내 모든 프로젝트에, 프로젝트 CLAUDE.md는 팀과 공유하는 규칙에 쓴다. CLAUDE.local.md는 나만 보는 메모로, .gitignore에 넣어 git에 올리지 않는다.

Claude가 스스로 적는 메모의 목차인 MEMORY.md는 프로젝트마다 따로 있고, 시작할 때 앞 200줄 또는 25KB까지만 읽는다. 메모가 길어지면 뒤쪽은 시작 때 안 들어간다는 뜻이다.

INTENT.md처럼 직접 이름 붙인 파일은 자동으로 읽히지 않는다. CLAUDE.md 안에 `@INTENT.md`처럼 적어야 함께 불러온다. 다른 도구용 AGENTS.md는 기본 설정에서 CLAUDE.md가 없을 때만 읽는다고 영상은 설명했다.
