관리형 설정(managed settings, 조직 관리자가 내려보내는 설정)에 들어 있는 훅이 불러와지지 않으면 Claude Desktop 같은 비대화형 환경에서도 대화 안에 경고를 띄운다. 조직이 보안용으로 걸어 둔 훅이 조용히 빠지는 일을 줄이려는 조치다.

/tasks 명령도 넓어졌다. 이번 세션의 예약 작업, /loop 깨우기, 목표(goal), 이 대화에서 갈라져 나온 포크가 한 화면에 나온다. x 키를 누르면 확인을 거친 뒤 하나를 멈춘다. 에이전트를 여러 개 돌리는 사람에게는 무엇이 뒤에서 돌고 있는지 한눈에 보는 창구가 생겼다.

MCP(Model Context Protocol, AI에 외부 도구를 붙이는 규약) 쪽에서는 /mcp의 서버 화면에 'Server message' 줄이 생겨, 원격 HTTP MCP 서버가 연결을 거부할 때 보낸 JSON-RPC 오류 문구를 그대로 보여 준다. 느린 재연결 뒤 멈추던 백그라운드 MCP 작업, octet-stream으로 온 PDF·이미지·오피스 파일이 .bin으로 저장돼 읽지 못하던 문제도 고쳤다.

전날 영상으로 소개된 실험 기능 코드 모드도 손봤다. OpenTelemetry 이벤트·지표를 켠 상태에서도 코드 모드를 쓸 수 있고, 코드가 부르는 도구 호출마다 이벤트가 남는다. 다만 트레이싱을 켜면 여전히 코드 모드가 꺼진다. Esc를 누른 뒤 끝난 편집이 사라지던 문제와 무한 루프가 메모리를 채우던 문제도 고쳤다.

기존 'Keep Activity' 설정은 두 항목으로 나뉜다. 채팅을 얼마나 오래 보관할지 정하는 'History(기록)'와, 채팅 내용을 AI 모델 학습에 쓸지 정하는 'AI training(AI 학습)'이다.

History를 끄면 Gemini는 이후 채팅을 약 두 달 보관한다. 응답하고 피드백을 처리하며, 사람 검토자의 도움을 받아 구글과 사용자, 대중을 보호하는 데 쓴다는 설명이다. 보도에 따르면 업데이트 전에는 저장을 끄면 72시간만 보관했으니, 끈 경우의 보관 기간은 오히려 길어졌다.

주의할 점도 있다. History를 꺼 두어도 피드백을 보내면 최근 24시간 채팅과 첨부 파일, 연결된 앱 데이터가 Gemini 개선에 쓰인다고 보도됐다. 'Keep Activity가 이미 꺼져 있었다면 새 두 항목도 기본으로 꺼진다'는 내용은 언론 보도에만 있고 공식 블로그에서는 확인되지 않았다. 업무 자료를 Gemini에 넣는 사람이라면 적용 뒤 두 항목을 직접 확인하는 것이 안전하다.

Claude Code의 실험 기능 '코드 모드(Code Mode)'를 켰을 때와 껐을 때를 비교한 유튜브 영상이 나왔다. 코드 모드는 Claude가 자바스크립트를 짜고, 그 코드 안에서 MCP 도구·파일 읽기·수정·명령 같은 도구를 직접 부르는 방식이다. 공식 문서와 변경 기록(2.1.323)에도 같은 설명이 있다.

영상은 차이를 이렇게 설명한다. 원래도 Claude는 grep·python 같은 터미널 명령으로 코드를 돌렸지만, 그 코드는 MCP 도구를 부를 수 없었다. 그래서 MCP로 받은 자료를 Claude가 먼저 다 읽고 옮겨 적어야 했다. 코드 모드에서는 걸러 내고 더하는 일을 내 컴퓨터 안에서 끝내고, Claude는 마지막 결과만 받는다.

제작자는 2026년 11월 20일 Claude Code 2.1.329, Opus 5.5, 자동 모드로 세 가지 일을 끔·켬 한 번씩 시켰다. 주문 1,000건이 든 예시 쇼핑몰 MCP 서버에서 10월 환불 상위 3명을 찾는 일은 53.4초에서 16.2초로, 입력 토큰은 83.2만에서 15.4만으로 줄었다고 했다. 파일 40개 중 14개 고치기는 22.6초에서 17.8초였고, 설정 파일 80개 뒤지기는 오히려 켠 쪽이 15.4초에서 17.2초로 느렸다. 모두 한 번씩 잰 값이라 공식 자료로 확인할 수 없고 편차가 있을 수 있다.

켜는 법은 공식 문서와 같다. v2.1.323 이상에서 CLAUDE_CODE_EXPERIMENTAL_CODE_MODE=1을 붙여 실행하고 확인 창에서 켠다. 계속 쓰려면 ~/.claude/settings.json의 env에 같은 값을 넣는다.

제한도 확인됐다. 대화형 터미널에서만 되고 -p, VS Code 확장 패널, 데스크톱 앱, Bedrock·게이트웨이에서는 안 된다. 켜 둔 동안 크롬 연동과 컴퓨터 사용이 꺼진다. 코드 안에서 생기는 도구 호출 하나하나는 deny·ask 권한 규칙과 훅을 그대로 거치므로, 꼭 막아야 할 명령은 규칙에 적어 두는 것이 좋다. 오늘 나온 v2.1.329에서는 OpenTelemetry와 함께 쓰는 길도 열렸다.

두 번째는 모듈러 부트스트랩이다. 한 에이전트가 기존 수치 결과에서 물리학자들이 놓친 미세한 패턴을 찾았고, 고차원 구 채우기 문제를 풀던 다른 에이전트가 만든 기법이 그 패턴을 푸는 열쇠가 됐다. 그 결과 Λ≈9.1266이라는 값을 정확한 식으로 구하고, 이 방법으로는 더 낮출 수 없다는 최적성까지 보였다고 했다.

눈여겨볼 대목은 문제 하나를 한 모델이 푼 것이 아니라, 여러 에이전트가 오래 돌며 서로의 결과를 빌려 썼다는 점이다. 긴 시간 돌아가는 다중 에이전트 작업이 연구 현장에서도 쓰이기 시작했다는 사례다. 다만 결과가 물리학계에서 얼마나 인정받을지는 앞으로 검증을 지켜봐야 한다.

구글 TPU 생산 분기 65% 늘었다는 추정…AI 칩 경쟁 가열

Epoch AI 추정으로 3분기 약 80만 개이며, 매출 전망과 젠슨 황 사임설은 확인 안 돼

구글의 AI 전용 칩 TPU(텐서처리장치) 생산이 빠르게 늘고 있다는 국내 기사가 공유됐다. AI 연구업체 Epoch AI에 따르면 구글의 TPU 개발 협력사 브로드컴의 올해 3분기 TPU 생산량은 약 80만 개로, 전 분기보다 65% 늘었다. Epoch AI 자료와 일치하지만 추정치라 나중에 바뀔 수 있다.

TPU는 구글이 2016년부터 만들어 온 AI 연산용 반도체다. 기사는 글로벌 빅테크가 전력 효율과 가성비를 이유로 엔비디아 GPU 대신 TPU 도입을 늘리고 있고, 구글과 협력하는 삼성전자가 메모리 공급으로 수혜를 볼 수 있다고 전했다.

기사 속 다른 두 주장은 확인되지 않았다. 블룸버그 인텔리전스를 인용해 구글 TPU 관련 매출이 올해 약 120억 달러에서 2028년 1,350억 달러 이상으로 늘 것이라고 했지만 원문을 확인하지 못했다. 또 기사는 엔비디아가 '젠슨 황 전 CEO 사임'으로 흔들린다고 썼는데, 이는 엔비디아 공식 자료로 확인되지 않았다.

AI 칩 공급이 한 회사에 몰리지 않고 늘어나면 장기적으로 모델 사용 값과 공급에 영향을 줄 수 있다. 다만 생산량은 추정치이고, 매출 전망과 경영진 변화는 확인이 필요하다.
