앤트로픽이 11월 9일 Claude Fable 5.2와 Claude Mythos 5.2를 함께 공개했다. 공식 발표문에 따르면 두 모델은 바탕이 같다. Mythos 5.2는 보안·생명과학 분야의 안전장치 일부를 뺀 판이고, Cyber·Life Sciences Verification Program 심사를 통과한 기관만 쓸 수 있다. 일반 사용자가 쓰는 쪽은 Fable 5.2다.

값은 내렸다. API 가격은 100만 토큰당 입력 8달러, 출력 40달러이고, 캐시 읽기(이미 읽은 앞부분을 다시 읽을 때 매기는 값)는 0.20달러다. Fable 5.1의 입력 10달러·출력 50달러에서 20% 내린 셈이다. 다만 Opus 5.5(입력 4달러·출력 20달러)와 비교하면 여전히 두 배다. 출력 속도는 Fable 5.1보다 최대 30% 빠르다고 발표문은 밝혔다. 돈을 더 내고 속도를 올리는 빠른 모드는 최대 2.5배 빠르고 값은 입력 16달러·출력 80달러다. API 말고 AWS, Google Cloud, Microsoft에서도 쓸 수 있다.

Claude Code도 같은 날 v2.1.321에서 새 모델을 반영했다. 릴리스 노트 첫 항목은 Claude Fable 5.2(claude-fable-5-2)를 추가하고 기본 Fable 모델로 삼았다는 내용이다. 컨텍스트는 100만 토큰이다. Claude Code에서는 /model fable로 고르고, 다른 모델의 조언자(Advisor)로 쓰려면 /advisor fable을 쓴다.

이번 릴리스에는 보안 관련 수정도 여럿 들어갔다. MCP 서버가 OAuth 요청을 다른 호스트로 돌려보낼 때 리프레시 토큰 같은 비밀값이 그 호스트로 넘어가던 문제를 고쳤다. 읽기 전용 Bash 명령이 권한 확인 없이 샌드박스 밖에서 돌던 경우, cp·mv로 폴더 안에 파일을 쓸 때 거부 규칙이 적용되지 않던 경우도 고쳤다. 훅(정해진 시점에 자동으로 도는 사용자 스크립트) 쪽에서는 PreToolUse 훅의 ask 응답이 다른 훅의 defer 때문에 사라지던 문제, 큰 훅 출력이 다른 훅의 출력 파일을 가리키던 문제가 바로잡혔다. 프로젝트 스킬·명령·에이전트가 git stash 같은 작업 뒤에 메뉴에서 사라지던 문제도 고쳤다.

출시 기념 혜택도 있다. 도움말 센터 안내에 따르면 Pro와 Team 표준 좌석은 11월 16일 23:59(태평양 시간)까지 주간 한도의 50% 안에서 Fable을 추가 비용 없이 쓰고, 한도 초기화를 한 번 받는다. Max·Ultra 등은 가입 기간에 따라 Fable 한도 초기화를 1~3번 받아 2027년 3월 8일까지 쓸 수 있다. 무료 요금제는 대상이 아니다.

발표문에는 출시 전 시연이 여럿 실렸다. Fable 5.2가 하위 에이전트 1,000개 넘게를 지휘해 빈 폴더에서 8일 만에 노트북에서 켜지는 운영체제를 만들었다. 에이전트 1,000개가 30시간 만에 페르마의 마지막 정리를 형식화(증명을 컴퓨터가 한 단계씩 검사할 수 있는 언어로 옮기는 일)했고, 같은 조건의 Opus 5.5는 18시간에 26%에 그쳤다. 로봇 가상 시험 RoboDojo Sim 점수는 27.6%에서 64.9%로 올랐다. 쓰는 법은 간단하다. 어느 세션에 무엇을 전할지 말하면 Claude가 대상을 찾아 내용을 쓴다. 받는 Claude는 도구 호출 사이에 메시지를 읽기 때문에 실행 중인 도구가 끊기지 않는다. 오래 걸리는 작업이 끝나면 지금 보던 세션에 한 줄로 알려 달라고 할 수도 있다. 프론트엔드와 서버를 다른 세션에서 나눠 작업할 때 특히 쓸모가 있다.
